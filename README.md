# DT224G - Laboration 6

[GitHub Pages](https://ask-leijonhufvud.github.io/dt224g_lab_6_ask_leijonhufvud/)

## Beskrivning

Detta är/var en skoluppgift med syftet att:
> * Förstå hur asynkron programmering används när data hämtas från externa källor.
> * Använda ```fetch()``` för att göra anrop till ett externt REST-API.
> * Använda ```async/await``` för att hantera asynkrona operationer.
> * Hantera och använda JSON-data som returneras från ett API.
> * Hantera fel som kan uppstå vid externa anrop.
> * Bearbeta hämtad data och presentera den dynamiskt i DOM.
> * Använda tidigare kunskaper om formulär, event, funktioner, arrayer, objekt och DOM-manipulation.
> * Strukturera JavaScript-kod i minder funktioner med tydliga ansvarsområden.
> * Använda Git och GitHub för att versionshantera programkod.

HTML- och CSS-filer tillhandahölls av lärarna.
